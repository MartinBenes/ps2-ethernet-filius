# Ethernet I · Filius

Interaktivní pracovní list pro studenty předmětu Počítačové sítě II.

[Otevřít pracovní list](https://martinbenes.github.io/ps2-ethernet-filius/)

Obsahuje návrh malé lokální sítě (30 minut), rozšíření do druhé místnosti (20 minut) a volitelný bonus s routerem. Studenti sestavují vlastní projekty v aplikaci Filius podle slovního zadání.

Odpovědi existují pouze v otevřené stránce. Přepínání úloh je zachová, obnovení nebo zavření stránky je smaže. Pracovní list nemá přihlášení, odevzdávání ani ukládání odpovědí.

## Úpravy a publikování

Stránka používá pouze HTML, CSS a JavaScript, bez závislostí a sestavování. GitHub Pages publikuje kořen výchozí větve. Soubor `.nojekyll` vypíná zpracování Jekyllem.

- `index.html` – zadání a formulář
- `styles.css` – vzhled a responzivní rozložení
- `app.js` – přepínání úloh, nápovědy a přehled postupu
- `favicon.svg` – ikona stránky

Pro místní náhled spusťte `python3 -m http.server 8000` v tomto adresáři a otevřete `http://localhost:8000/`.
